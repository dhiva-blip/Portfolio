I'm Dhiva, a frontend web developer who enjoys turning a business's story into a website that actually gets people to act — book a table, place an order, or send an enquiry.

My work centers on user experience, performance and modern design. Every page I build starts from the same three questions: who's landing here, what do they need to see first, and what's the one action that matters? Everything else — animation, color, layout — is built to support that.

I work mainly with startups, cafés, restaurants, clothing stores and small local businesses that need a website which loads fast, looks credible on a phone, and is easy to hand off — clean, well-commented code, no unnecessary dependencies.

When I'm not shipping landing pages, I'm refining my own toolkit: accessibility, micro-interactions, and squeezing out every unnecessary kilobyte.
